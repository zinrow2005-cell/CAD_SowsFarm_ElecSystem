# V11.7.2｜CAD 操作列不遮擋底圖

## 使用方式

1. 平常直接單指或滑鼠拖動畫面：不需要再點「瀏覽／拖曳」，系統預設即為瀏覽模式。
2. 若要查欄格，點擊右上角與 +、−、全場並排的 **⌖ 查欄**；按鈕改為 **✋ 拖曳** 表示目前正處於查詢模式。
3. 輕點欄格後只出現底部資訊小卡；按「查看設備詳情」才開大型視窗，按「完成查詢」或右上 **✋ 拖曳** 即退出查詢。
4. 一般瀏覽模式不會誤觸開啟欄格視窗；拖曳及雙指縮放也不會觸發選取。

## 安全與更新

保持原有設備、照片、線路及 .hwpack 格式；更新前備份你的個人檔案，且勿覆蓋既有 equipment-data.json。正式 iPad Safari 需要部署後再驗證。
