# V11.8.3 手機 CAD 縮放優化：操作與測試紀錄

## 修正緣由

V11.8.2 的 `cad-inline-1.js` 在每個 `pointermove` 都呼叫 `map.setAttribute('viewBox', ...)`，會讓瀏覽器頻繁重新繪製包含 155 個圖層的 SVG；尤其手機雙指縮放會感受到卡頓。

## 新版流程

1. 手指壓下，記下當前 viewBox、畫布尺寸及觸控起點。
2. 手指移動時只更新 CSS 平移／縮放，並以 `requestAnimationFrame` 合併連續事件，不變更 SVG 原始線段。
3. 雙指中點作為固定縮放基準，同時可平移；觸控根數轉換時提交並重設基準。
4. 手指離開時依 `preserveAspectRatio=xMidYMid meet` 的留白計算精確 `viewBox`，清除暫時的 CSS 變換。
5. 保留工具列縮放、全圖、欄格查詢、設備管理與拖曳防誤觸功能。
