# 虎尾母豬場 CAD V11.7｜完整設備、照片與線路可攜式備份

## 核心操作方式

使用其中一台電腦／手機／平板當作主要編輯裝置，現場拍照後，從 CAD 的**設備圖標**開啟該設備照片，標註配電箱開關、端子、迴路用途、水路或飼料設備。這些百分比位置標記保存於設備資料，**不燒錄到照片本體**，因此日後修改標籤時不必重拍。

全部建立完成後，使用「**▣ 完整專案備份**」匯出 `.hwpack`；再將備份放到自己指定的檔案夾、USB、NAS 或手動上傳私人 Google Drive 資料夾。另一裝置安裝／開啟**相同 CAD 底圖版本**的網站，即可選取該檔案還原。**不需要 Google Drive API 或 Firebase 即時同步**。

## 匯出備份

1. 從 GitHub Pages **HTTPS** 網址開啟系統，切換本機管理者模式。
2. 確認設備照片、開關標記和管線關聯已儲存；建議先在「系統健檢」檢查缺檔與待核對資料。
3. 開啟「**▣ 完整專案備份**」（電腦側欄、手機「備份」或舊備份區的新版入口）。
4. 設定至少 12 個字元的密碼，按「**① 製作加密備份檔**」。
5. 等待每張照片和專案資料加密完成；**這時還沒儲存到硬碟**。
6. 按「**② 儲存到我的檔案夾**」。支援的桌機瀏覽器可選擇檔案儲存位置；手機／平板通常儲存到系統下載位置，再用「檔案」移動到指定資料夾。
7. **親自確認 `.hwpack` 實際存在，記下備份密碼，並至少在另一裝置試還原一次。** 密碼遺失無法解密。

備份會包含：設備資訊、實際 CAD 座標、電線、水管、送料管、氣流示意、端子與斷路器、照片標記、照片縮圖、存在時的高解析主圖、母子系統及其關聯、維修／巡檢紀錄、欄格容量與設備綁定。CAD **底圖本身及網站程式不打包**；備份包含該圖面的版本指紋，避免不同版本座標錯位。

## 換裝置匯入

1. 在另一裝置開啟**相同 CAD 工作底圖版本**的 HTTPS 網站。
2. 「完整專案備份」→「↑ 換裝置匯入」→ 選取 `.hwpack` → 輸入密碼。
3. 點「**檢查備份並預覽**」：系統會逐一解密／驗證每張照片；此步驟不修改本機資料。
4. 比對設備、管線、照片、標記、維修、系統樹、欄格關聯數量及備份日期，確認不是較舊的檔案。
5. 若目前裝置已有資料，先另存該裝置自己的完整備份。勾選確認，再手動輸入「**覆蓋**」。
6. 按「**確認整份取代並還原照片**」；待完成後重新開啟 CAD、照片與開關標記逐項核對。

**還原不會合併兩台裝置各自編輯的差異。** 例如 A 裝置編輯後匯出，B 裝置再修改，不能在沒有比對的情況下把舊版 A 檔匯回 B，否則較新資料會被取代。

## 技術保護與相容性

- 新格式 `.hwpack` 採 PBKDF2-SHA256 260,000 次迭代衍生 AES-256-GCM 金鑰；專案清單與照片內容分項加密，照片逐項另作 SHA-256 校驗。
- 加密密碼不寫入 localStorage，沒有上傳至網站伺服器。
- 匯入會先檢查圖面版本指紋、設備資料格式、照片 ID 對應、欄格關聯、完整密文及雜湊；拒絕損毀或不匹配的備份。
- 新格式有約 **360 MB 的單檔封裝上限**。若全場照片量超出，應使用桌機減少不必要的重複照片或規劃分區保存，而不是默默遺漏部分照片。新照片主圖最多 4096px；舊照片只有縮圖時備份也只能保留該縮圖，無法重新還原為原始解析度。
- 為避免瀏覽器流失操作權限，製作加密檔與按下系統存檔按鈕分成兩步。按下製作成功不代表檔案已下載。
- **V9.2～V11.6.1 舊 `.hwb`** 可透過備份頁的「舊版 .hwb 相容工具」匯入；舊備份容量限制仍然存在。新 `.hwpack` 不等於可由舊版本系統反向讀取。
- 主設備 JSON 放在 localStorage，高解析照片與縮圖分別在不同 IndexedDB。**瀏覽器沒有跨多個資料庫的原子交易**；若還原時儲存空間不足，可能發生部分寫入。必須先備份舊裝置、使用容量充足的目標裝置，匯入後再做完整核對。
- 一份 `.hwpack` 是**私密檔案**，可能透露全場管線及配電配置。請勿把備份或密碼放在公開 GitHub 專案。若使用 Google Drive，請手動儲存至私人資料夾，不需要將照片設定為「知道連結者皆可存取」。

## 正式上線／實體設備測試尚待驗證

本版已通過 Node WebCrypto 加解密、照片與端子完整性測試、80 張圖片封裝測試，以及 Chromium 桌機／平板／手機**介面模擬**。但此工具環境不能使用 GitHub Pages 真實 HTTPS 網址進行瀏覽器存取，因此**尚未**在實體 iPad/iPhone、真正 IndexedDB 持續儲存、真實檔案選取器及跨裝置完整復原驗證。正式長期唯一資料來源前，務必完成兩台裝置驗收。
