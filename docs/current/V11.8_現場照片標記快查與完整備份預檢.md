# V11.8 現場照片標記快查與完整備份預檢

## 查詢配電開關

1. 使用「⌕ 全場設備搜尋」輸入開關名稱、控制用途、配電箱或照片名稱，例如「送料開關」。
2. 點選標示「照片標記」的搜尋結果，確認所屬設備與開關端子。
3. 按「📷 開啟照片並選取標記」，開啟原設備的原始照片與該標記。
4. 在照片內展開「開關／設備標記清單」，可以按開關名稱再次定位；管理者可透過現有標記編輯表單修改文字及迴路關聯。

**備註**：搜尋的是已建檔文字，不代表現場接線已經被核實。圖片仍存在本機 IndexedDB；換裝置前需要使用完整 `.hwpack` 匯出與還原。

## 加密備份前的檢查

1. 開啟「完整專案備份」。
2. 按「備份前檢查照片／開關標記／資料關聯」。
3. 確認照片缺失為 **0**；如果有資料關聯錯誤，可先進入「系統健檢」逐項核實。待現場核對的線路不會被擅自當成已核對。
4. 輸入長密碼、製作加密 `.hwpack`、按「儲存到我的檔案夾」。
5. **到檔案夾確認檔案真正存在**，並在另一台裝置先做還原檢查，才能算有效備份。

還原時會先檢查整份加密檔案，經兩步確認後覆蓋本機；事後另做照片完整性檢查。這不是跨 IndexedDB 與 localStorage 的單一交易，因此還原前應先保留舊裝置備份。

## 保留設定

- CAD 仍是瀏覽拖曳優先；要查夾欄才切換「⌖ 查欄」。
- 不重新繪製 CAD 的外牆、欄位及公豬欄。
- 不需要 Google Drive API、Firebase 即時同步，也不需將私人的照片上傳公開 GitHub。
- 專案僅包含 GitHub Pages 部署檔案，正式照片與資料不在 ZIP 內。
