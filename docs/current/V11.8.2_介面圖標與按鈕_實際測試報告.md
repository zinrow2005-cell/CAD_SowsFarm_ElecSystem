CAD 放大／縮小／回復、標註模式切換、基本圖面與設備工具分頁、員工與管理者模式、欄格查詢模式、妊娠 B 棟三排 82／82／80、污水池層與公豬欄符號、欄位容量、欄位快速定位、三種水源、母子系統、電力配電、全場搜尋與維修、系統健檢、完整備份介面的啟動與關閉。另以測試資料驗證設備建立、選取、名稱編輯和圖標出現在 CAD 上。

### 本次實際修正

1. 桌機側欄與瀏覽器標題仍顯示舊版本 V11.8 → 統一顯示 V11.8.2。
2. 手機上方「備份」文字因寬度不足上下換行 → 調整手機工具列間距、禁止按鈕文字換行。
3. 手機「系統架構」入口過長 → 簡化顯示為「系統」，保留完整無障礙名稱與提示。
4. 320 px 窄螢幕下各頂部入口完整可見，沒有壓住 CAD。
