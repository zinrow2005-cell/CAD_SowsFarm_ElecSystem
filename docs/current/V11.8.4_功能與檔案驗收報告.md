# V11.8.4 功能與檔案驗收報告

- 桌機 1440×900、手機 390×844、平板 820×1180 Chromium 模擬載入測試通過，無 JavaScript `pageerror`。
- 原始 CAD 155 層不變，新增加獨立**顯示**層 1 層（不計入原始 CAD 圖層，僅負責標註文字）。
- 文字總計 391 個節點，其中預設顯示的 64 個；60 組含文字圖層同步可見狀態。
- 一般放大／全圖按鈕，原圖與文字顯示層的 viewBox 同步。
- 模擬連續 14 幀雙指縮放時，原圖 viewBox 在手勢結束前維持不變、文字圖層逐幀更新；放開後兩個 viewBox 恢復完全一致。
- 測試中同一 CAD 文字在背景與獨立文字層的螢幕座標差最大約 0.000016 px（390px 模擬畫面），無明顯偏移。
- 棟舍名稱圖層切換與文字比例（135%）同步成功。
- 獨立文字層的文字描邊樣式為 `stroke: none`，避免暫存重繪時黑色字框；各文字保留來源圖層顏色。
- 測試僅為 Chromium 模擬，**尚未於真實 iPhone／iPad Safari 驗證帧率、字體快取或長時間使用**。
- 原始 DXF、CAD SVG 幾何未修改，設備資料／照片備份格式未修改。
