# V11.8.4 手機 CAD 文字即時向量渲染

## 修正目標

放大／縮小期間，棟舍名稱、面積、尺寸、欄位標示短暫變黑或延遲刷新。

## 修正內容

將 CAD 靜態文字從底圖 GPU 合成圖層分離，建立獨立 `#cadLiveLabels` SVG；底圖手勢期間仍只做 CSS transform，文字使用即時計算的 `viewBox`，每個動畫幀獨立以向量方式清晰繪製，避免低解析字形快取。文字來源與圖層勾選／字體倍率仍以原資料為準。

## 現場驗收步驟

1. 在手機開啟正式 HTTPS 網站，切換至「完整標註」，顯示棟舍、區域、面積及尺寸。
2. 以雙指連續放大、縮小並平移，觀察是否仍有黑字、短暫消失或縮放結束跳位。
3. 切換「純底圖」「名稱＋面積」等顯示模式，確認文字出現與隱藏正確。
4. 調整 CAD 文字比例，確認各圖層字體同步變大或變小。
5. 測試點選設備及公豬欄，小卡、線路、照片功能不受影響。

**限制：** 本機 Chromium 測試不能代替 iOS Safari 實機驗收。如仍有殘影，請回報裝置型號、iOS 版本與短影片。
