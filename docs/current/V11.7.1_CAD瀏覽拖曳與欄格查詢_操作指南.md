# V11.7.1｜CAD 瀏覽拖曳防誤觸與欄格查詢指南

## 主要修正

原本畫面上的真實欄格都能點擊，滑鼠按下拖曳和觸控滑動容易觸發欄格資訊視窗；尤其原有 CAD 的 `#canvas` 設定了 Pointer Capture，正常點一下夾欄後 `click` 事件也可能被轉送給整張畫布。V11.7.1 同時修正這兩個操作問題。

- **✋ 瀏覽／拖曳（每次開啟的預設模式）：** 可以拖曳 CAD、放大縮小；點到夾欄不會跳出設備視窗。原有設備圖標仍可按用途選取。
- **⌖ 欄格查詢：** 先切換到此模式，再輕觸單格。只會出現底部小資訊卡，包含欄位名稱、編號及既有設備關聯摘要。**沒有登錄關聯並不表示現場沒有設備**。
- **查看設備詳情：** 從小卡按下才開啟原有完整欄格設備關聯視窗。
- **完成查詢／Esc：** 清除小卡並回到瀏覽模式。搜尋欄格編號的既有明確入口仍可使用。
- **防誤觸：** 滑鼠按下後移動超過約 8px 或觸控滑動超過約 12px 視為拖曳，不應啟動夾欄資訊；兩指操作不觸發欄格點擊。
- **手機介面：** 小卡顯示時暫時隱藏右下角的全場搜尋／迴路快捷浮動按鈕，避免遮住操作區；關閉小卡後恢復。

## 進場驗收建議

1. 正式 GitHub Pages 更新後，重開網頁，確認版本 V11.7.1，預設亮起「✋ 瀏覽／拖曳」。
2. 用手機手指按住一排夾欄滑動 CAD，確認不彈出欄格視窗。
3. 用雙指縮放 CAD，確認不跳出任何設備視窗。
4. 切換「⌖ 欄格查詢」，輕觸一格，確認只顯示底部小卡；選「查看設備詳情」才顯示完整欄格關聯介面。
5. 切換回瀏覽模式，確認設備圖標、設備照片、管線及 `.hwpack` 備份功能未受到影響。
6. 如果手機顯示舊版介面，可關閉舊分頁後重新開啟，或清除單一網站的快取；**不要清除網站資料／IndexedDB**，避免遺失照片。
