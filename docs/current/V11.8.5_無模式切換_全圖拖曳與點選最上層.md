# V11.8.5｜全圖自由拖曳與設備選取優先

* 移除右上角「⌖ 查欄／✋ 拖曳」切換按鈕。
* 電腦左鍵按住移動，或手機／平板單指滑動：不論起點位在背景、欄格或設備圖標，都移動整張 CAD。雙指照常縮放。
* 單點／輕觸母豬夾欄：顯示底部小卡，再由使用者決定是否打開完整資料。
* 單點／輕觸設備圖標：選取該設備，SVG 圖標移到設備圖層最前面，避免被其他設備圖標擋住；不更改其真實座標。
* 單點管線可選取管線，滑動則不觸發查詢。
* 管理者需要移動設備圖標顯示位置：在 Windows 電腦按住 **Alt＋滑鼠左鍵**拖動，或在編輯面板調整位置。一般拖曳不會改設備位置。
* 管理者使用放置設備／畫線功能時，點按仍執行現有編輯操作。
* 既有照片、標記、母子系統、配電、水路、送料、備份格式及 CAD 幾何完全保留。
* 不會在新的 `.hwpack` 版本中寫入操作模式設定。

## 實機測試建議

1. 從欄格中央與設備圖標中央開始連續滑動，確認只移動 CAD。
2. 直接輕觸欄格，確認顯示小卡，不需要切換模式。
3. 單點兩個相鄰設備，確認最後選取的圖標顯示在前方。
4. 連續雙指縮放後，立即輕觸欄格，應無誤觸或錯位。
5. 使用相同備份匯入／匯出進行回歸驗證。

本版測試使用 Chromium 模擬滑鼠與觸控；實體 iPhone/iPad Safari 尚待使用者現場測試。
