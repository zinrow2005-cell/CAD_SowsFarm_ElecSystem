# 虎尾場 CAD 設備配置系統｜V11.7 GitHub 網頁上傳精簡版

## 為什麼只有這些檔案？

GitHub 網頁「Upload files」一次上傳可選取的檔案有數量限制。本包只保留 **V11.7 網站實際載入的 HTML／JavaScript／CSS**，以及正式 CAD 原始工作圖（供離線備查）、必要的現行操作文件和空白設定範例。**不含舊版截圖、歷史測試紀錄與多代操作手冊**，也不含任何現場照片、私人備份或正式設備資料。

- 正式進站頁面：`index.html`（位於根目錄）
- 執行程式：`assets/js/`
- 樣式：`assets/css/`
- 工作 CAD／DXF 與欄位索引：`cad/`（網站 SVG 底圖已內嵌在 `index.html`）
- 現行備份／系統樹操作指南：`docs/current/`

## 上傳 Github Pages（使用網頁介面）

1. **先在舊版系統匯出完整 `.hwpack`，並確認已存入個人檔案夾。**
2. 開啟 ZIP 並解壓縮，請拖曳 **解壓後資料夾「裡面的所有檔案與子資料夾」**，而不是拖曳外層資料夾，至 GitHub 儲存庫根目錄的 `Add file → Upload files`。
3. 確認上傳的路徑包含根目錄 `index.html`、`assets/js`、`assets/css`。不要改動子資料夾路徑，也不要把 ZIP 當成網頁直接上傳。
4. GitHub 完成提交後等 Pages 更新，在正式 HTTPS 網址測試 CAD、母子系統、照片與「完整專案備份」。
5. **如果舊儲存庫已有 `equipment-data.json`，必須保留舊檔，不要以空白檔覆蓋或刪除。** 本包不提供根目錄的 `equipment-data.json`。

注意：上傳精簡包不會自動刪除儲存庫中以前上傳的過時檔案。這不影響新版 `index.html` 所載入的程式，但舊檔若要清理請另行進行並先備份。

### 資料安全

- 只有 `.hwpack` 是包含照片本體的加密專案備份；**不可把你的 `.hwpack` 或正式設備資料上傳公開 GitHub 儲存庫**。
- 瀏覽器內本機編輯資料不一定隨著換裝置同步。請使用 `.hwpack` 備份與還原。
- 不需要 Google Drive API；若要存到 Google Drive，可自行把下載的備份檔放進私人雲端資料夾。
- 新站仍需以真正手機／平板做跨裝置照片備份與還原驗收，不能只根據程式語法檢查就視為已經正式通過。
