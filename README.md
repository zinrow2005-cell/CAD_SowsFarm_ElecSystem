# 虎尾母豬場設備配置系統 V11.12.6 — 浮動工具列重疊修復

## 本版改動
- 修復 V11.12.4 原有「設備狀態」與「水電關聯」同一位置重疊。
- 桌機右上角的 CAD 縮放、搜尋、設備狀態、關聯追蹤整合到一個不交疊的工具列。
- 手機將狀態、關聯、設備與維修、配電迴路四種查詢入口收納至「查詢工具」，避免底部重複浮動按鈕遮擋圖面。
- 設備配置工作台的多選／復原／重做工具與新工具列分開，避免覆蓋。
- 側欄或編輯視窗打開時，手機查詢工具會避讓；原有功能與資料檔案格式不變。
- PWA 快取版本升級，加入新增的浮動工具排列模組。

## GitHub Pages 更新
將 ZIP 解壓縮後的檔案與資料夾放到專案根目錄；舊版未自動刪除的檔案仍可由 GitHub Desktop 清理。部署前先匯出並保存 .hwpack，請勿清除裝置的 PWA 本機儲存。

## 測試限制
通過隔離 Chromium 的跨尺寸版面與按鈕互動測試。未直接操作使用者裝置，未重驗所有照片、維修資料及 .hwpack 真實跨裝置還原流程。


### V11.12.6 備份操作修正
- 匯出／匯入頁籤會明確顯示目前狀態，重複點選匯出頁籤會引導到真正的「開始製作完整備份」按鈕，不會使已完成的下載檔失效。
- 開始備份即顯示進度，逐張照片讀取時有明確回饋；無回應逾時會提示，不會靜默忽略遺失照片。
- 成功製作後會出現可點擊的 `.hwpack` 下載按鈕，並提示確認檔案已存在。
- 新版免密碼格式 HWPN121! 不變；保留舊加密備份預覽支援。
- 測試包含真正的備份加密結構讀寫與資料、照片 SHA-256 往返，以及桌機、手機、平板尺寸的按鈕點擊與下載／預覽；實體 iOS Safari 尚未直接驗收。
