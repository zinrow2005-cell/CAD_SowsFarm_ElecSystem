# 虎尾場 CAD 設備配置系統｜V11.8 現場照片標記快速查詢與備份預檢版

## 為什麼只有這些檔案？

GitHub 網頁「Upload files」一次上傳可選取的檔案有數量限制。本包只保留 **V11.8 網站實際載入的 HTML／JavaScript／CSS**，以及正式 CAD 原始工作圖（供離線備查）、必要的現行操作文件和空白設定範例。**不含舊版截圖、歷史測試紀錄與多代操作手冊**，也不含任何現場照片、私人備份或正式設備資料。

- 正式進站頁面：`index.html`（位於根目錄）
- 執行程式：`assets/js/`
- 樣式：`assets/css/`
- 工作 CAD／DXF 與欄位索引：`cad/`（網站 SVG 底圖已內嵌在 `index.html`）
- 現行備份／系統樹操作指南：`docs/current/`

## 上傳 Github Pages（使用網頁介面）

1. **先在舊版系統匯出完整 `.hwpack`，並確認已存入個人檔案夾。**
2. 開啟 ZIP 並解壓縮，請拖曳 **解壓後資料夾「裡面的所有檔案與子資料夾」**，而不是拖曳外層資料夾，至 GitHub 儲存庫根目錄的 `Add file → Upload files`。
3. 確認上傳的路徑包含根目錄 `index.html`、`assets/js`、`assets/css`。不要改動子資料夾路徑，也不要把 ZIP 當成網頁直接上傳。
4. GitHub 完成提交後等 Pages 更新，在正式 HTTPS 網址測試 CAD、母子系統、照片與「完整專案備份」。
5. **如果舊儲存庫已有 `equipment-data.json`，必須保留舊檔，不要以空白檔覆蓋或刪除。** 本包不提供根目錄的 `equipment-data.json`。

注意：上傳精簡包不會自動刪除儲存庫中以前上傳的過時檔案。這不影響新版 `index.html` 所載入的程式，但舊檔若要清理請另行進行並先備份。

### 資料安全

- 只有 `.hwpack` 是包含照片本體的加密專案備份；**不可把你的 `.hwpack` 或正式設備資料上傳公開 GitHub 儲存庫**。
- 瀏覽器內本機編輯資料不一定隨著換裝置同步。請使用 `.hwpack` 備份與還原。
- 不需要 Google Drive API；若要存到 Google Drive，可自行把下載的備份檔放進私人雲端資料夾。
- 新站仍需以真正手機／平板做跨裝置照片備份與還原驗收，不能只根據程式語法檢查就視為已經正式通過。

## V11.7.2 CAD 手勢與欄格查詢

- 開啟網頁預設為「✋ 瀏覽／拖曳」：夾欄不會彈出資訊視窗，但原有設備圖標仍可點選。
- 要查欄格時，點選 CAD 右上既有放大／縮小工具列中的「⌖ 查欄」，再輕觸單格。先顯示底部小卡，按「查看設備詳情」才會開啟完整關聯工作台。
- 拖曳、雙指縮放與取消手勢均攔截誤觸事件；滑鼠移動超過 8 px、觸控移動超過 12 px 視為拖曳。
- 點「完成查詢」、按 Esc 或開啟詳細資訊後，回到拖曳模式。
- 使用「欄格定位與設備關聯」的**明確搜尋按鈕**仍可直接定位及開啟管理介面，不受瀏覽模式限制。
- 未修改 CAD SVG 畫線、欄位容量、設備／照片、線路、備份格式或 DXF。

### 測試界線

桌機／手機／平板瀏覽器模擬並不等於實體 Safari 的驗收；部署後請用實際 iPhone／iPad 驗證單指拖曳、雙指縮放、快速選取及設備點選。

## V11.7.2 操作列精簡修正

- 移除畫面上覆蓋 CAD 的「✋ 瀏覽／拖曳／⌖ 欄格查詢」大型兩鍵操作列，以及下方常駐文字提示。
- 直接將一顆精簡的「⌖ 查欄」按鈕放入 CAD 右上原有的「＋／−／全場」工具列，同一位置切換為「✋ 拖曳」。不再額外佔用畫面中央／左上空間。
- 預設就是自由瀏覽／拖曳，查詢時按一下「⌖ 查欄」，選取欄格後只顯示底部小卡，選「完成查詢」後恢復拖曳。
- CAD 畫線、夾欄、圖層和設備資料、照片、備份格式及 DXF 都沒有更動。


## V11.8 新增功能（2026-10-18）

1. 全場搜尋可直接找 **設備照片名稱、照片開關標記、標記說明與端子用途**。例如搜尋「送料開關」或「送料馬達」，選擇「照片標記」結果，即可跳到對應設備照片上的標記。搜尋類型亦新增「照片／開關標記」。結果使用原始設備 ID／照片 ID／標記 ID，不另外複製照片。
2. 照片管理新增 **可展開的開關／設備標記清單**，直接選一個標記即可進入既有標記編輯／檢視；百分比定位不變。縮圖清單改優先讀取小圖，降低大量照片在手機上的記憶體負擔。
3. 完整專案備份畫面新增 **「備份前檢查照片／開關標記／資料關聯」**，顯示本機高解析照片、僅縮圖、缺失照片、標記數量與異常／待核對資料；發現照片缺失時拒絕標示為成功備份。
4. 完整 `.hwpack` 還原之後，新增本機照片索引與缺失照片核對；系統健檢內「加密完整備份」按鈕改成開啟新版 `.hwpack` 工作台，不再優先跳到舊式 `.hwb`。
5. **保留 V11.7.2 預設拖曳及右上角「⌖ 查欄」簡短模式切換**；原始 CAD／DXF／欄位幾何及備份 `.hwpack` 格式均無更動。

### V11.8 的驗收界線

- 已使用模擬設備、端子、照片標記，驗證搜尋 → 標記詳情 → 原設備照片；備份預檢可發現缺失照片。
- 新格式沿用 V11.7 `.hwpack`，使用 Node.js WebCrypto 測試單張示範照片加密、解密、標記保留、錯誤密碼和密文變造拒絕；大量照片上限及 iPhone／iPad 真實裝置還原仍未驗收。
- 瀏覽器模擬不等同現場 Safari。正式用途前務必在另一部裝置實際匯出與還原一次，確認高解析照片能放大、標記仍能點選。
