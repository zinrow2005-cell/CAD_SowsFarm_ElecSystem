# V11.12.17｜四棟中央走道進出門位置修正

使用者將原先錯誤的紅圈門位指向藍圈新位置。本次**只移動四處**：A、C 棟的北端中央走道門（門1），B、D 棟的南端中央走道門（門2）。原有另外四處入口沒有更動；四棟合計仍是八門、150 張產床，三排與床頭朝向不變。

牆面實際缺口、門片直線、90° 開啟弧、隱藏門洞定位線、編號與 `cad/current/` DXF 已同步修正。原版 DXF 及版本校核 JSON 存入 `cad/reference/`。改版不修改既有設備及 `.hwpack` 資料格式。

**尺寸說明：**藍圈屬位置示意，不含門洞中心離角落的實測尺寸。新門位置用每棟沿牆「北端約 6.5%／南端約 95%」預置，門寬暫保留 0.55m 的上一版草案；請現場核對後方可當施工圖。

# 虎尾母豬場設備配置系統 V11.12.17｜中央走道四處門位依藍圈修正（待核圖）

## 完成的 CAD 修改

- 產房 A：42 床（14×3 排）。C：36 床（12×3 排）。北→南依序：100cm、北排頭北、60cm、中排頭南、100cm、南排頭北、60cm。
- 產房 B、D：各 36 床（12×3 排）。北→南依序：60cm、北排頭南、100cm、中排頭北、60cm、南排頭南、100cm。
- 保留 150 床編號、不移動棟舍外牆；將三排產床以外牆現有尺寸推算深度重新排入，並在每床新增朝向箭頭。
- 中央走道側的 A、B、C、D 棟：原本每棟一處門洞改為**每棟兩處門洞的圖片推估草案**（合計八處，先讓門洞中心對齊北／中排與中／南排之間的走道（0.6m 走道用約 0.55m 示意門、1.0m 走道用約 0.90m 示意門）），原門線從外牆和門扇圖層移除，不留下重疊門。
- 實際門洞數量、距離北端牆位置、寬度及門扇開啟方向須**現場核對**；不能憑圖片視為最終施工尺寸。
- 新增三個可選圖層：產床頭向（預設開）、產房南北走道配置（預設關）、中央走道門號_待核（預設關）。
- `cad/current/` 下的 DXF 隨新圖面重新產生同樣的產床、門洞與牆線幾何；`cad/reference/` 保留舊版 SVG 和 DXF 用於比對。
- 原設備、水電、料管、照片、`.hwpack` 格式及 CAD **座標系統**均保留；備份校驗仍使用同一座標相容指紋，避免僅調整產房底圖就阻擋舊版備份還原。

## 待確認的重要尺寸

原 CAD 產床深度約 1.93m，但用既有牆體寬度和你指定走道寬度反推後，更新的產床深度約 2.54–2.88m。因使用者尚未提供現場產床實際深度及門位離牆尺寸，**產床深度與八處門位均屬候選圖面，不代表已測量**。一旦有精確測量值，應再修訂正式 CAD。
