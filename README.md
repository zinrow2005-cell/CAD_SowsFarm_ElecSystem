# V11.12.18｜iPhone／iPad Google 雲端硬碟備份選取與分享

- **匯入：**「選擇備份檔」改為開放檔案類型的 iOS 文件選擇器，不再依副檔名篩掉 Google Drive 提供的 .hwpack；選完仍使用原本檔案標頭與 SHA-256 完整性驗證，並需手動確認還原。
- **iPhone/iPad：**請先登入 Google Drive App，打開「檔案」App →「瀏覽」→「⋯」→「編輯」→啟用 Google Drive，再回系統選檔 →「瀏覽」→「位置」→「Google Drive」。較舊 iOS 的選項名稱可能不同。
- **匯出：**建立且驗證 `.hwpack` 後，若瀏覽器支援分享檔案，出現「用系統分享備份」；可於系統分享表單選擇 Google Drive 或「儲存到檔案」。不支援者保留下載方式。
- **限制：**無法從網頁強制顯示某個 iOS 雲端位置；必須由作業系統的檔案提供者啟用。無雲端 API 授權、自動同步或背景上傳；分享動作不能取代實際確認檔案存在。
- **安全：**新版免密碼 `.hwpack` 未加密，請只放私人 Google Drive 資料夾，不要公開分享。保留原裝置資料，直到另一台裝置成功還原驗證。
- 保留 V11.12.17 產房中央門位修正、CAD 圖層／DXF、設備資料和全部既有功能。

## 待確認的重要尺寸

原 CAD 產床深度約 1.93m，但用既有牆體寬度和你指定走道寬度反推後，更新的產床深度約 2.54–2.88m。因使用者尚未提供現場產床實際深度及門位離牆尺寸，**產床深度與八處門位均屬候選圖面，不代表已測量**。一旦有精確測量值，應再修訂正式 CAD。
