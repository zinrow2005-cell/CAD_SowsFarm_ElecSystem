# 虎尾母豬場設備配置系統 V11.12.14 — 照片標記 A4 單頁列印

## 版本重點

在原版「設備照片與線路 → 照片與標記」中新增 **🖨 A4 標記列印**，不改動照片或設備資料。

- **只列印目前選取的照片**，避免同一設備多張照片誤印。
- A4 直式一頁版型：上方設備／區域／照片名稱，中間原照片，標記數字移到照片外圍；引導線回指精確的標記位置，不遮住設備上的開關位置。
- 下方按照標記順序列出編號、標記名稱、**完整功能說明**以及對應的開關／端子名稱；不在照片上鋪排長篇文字。
- 畫面自動安排編號間距及對照表欄數、字級，避免彼此遮擋；不會因為列印而修改標記原有的百分比座標。
- 支援列印預覽、瀏覽器列印、瀏覽器「另存為 PDF」，另外可下載固定 A4 比例的 PNG 圖檔。
- 原始照片先讀高解析主圖；若只有縮圖就改讀縮圖，沒有照片時顯示錯誤，不會印出空白圖。
- **若文字量多到無法在一張 A4 以可讀字級完整呈現，會明確拒絕列印並提示精簡說明，不會悄悄裁掉資料或印成第二張。**
- 列印圖像只在本機瀏覽器產生；不透過外部圖片或 PDF API 傳送照片。
- 保留 V11.12.13 既有電線、水管、送料管、通風線路自由邊線吸附，以及照片標記鎖定、快速資訊卡、端子與供電追蹤功能。

## 操作步驟

1. 在 CAD 圖上選取設備，開啟「📷 照片／迴路」→「照片與標記」。
2. 選好要印的照片；先確認所有標記名稱與功能說明已填寫完成。
3. 按照片工具列的「**🖨 A4 標記列印**」。
4. 確認預覽的照片、編號與功能對照表皆正確。
5. 按「**列印／存成 PDF**」，在瀏覽器系統列印視窗設定 A4、單面、實際大小、關閉頁首頁尾；要轉 PDF 就選「另存為 PDF」。
6. 若手機無法使用列印服務，可按「儲存 A4 圖檔」保存 PNG，再由手機內建列印／分享工具輸出。

## 資料與安全

- 不變更 `.hwpack` 容器、CAD 圖檔、設備、照片或標記的存放結構。
- 不自動上傳照片、列印圖或標記至 GitHub；**私人照片及完整備份不要放公開儲存庫**。
- 更新 GitHub 前，務必先保存目前系統的完整 `.hwpack` 於自己的資料夾；上傳 ZIP **解壓後的內容**到 GitHub Pages 實際部署的目錄。
- 重新開啟網站的 `release.json`，確認 `version = 11.12.14`、`revision = r6-a4-photo-print`。
- 避免自行清除瀏覽器網站資料，以免影響尚未備份的本機資料。
