# 虎尾母豬場設備配置系統 V11.12.4 — 清理整理版

本部署包由 V11.12.3 清理而來，保留 CAD、設備、照片、巡檢、管線、自由角度/吸附與免密碼完整 `.hwpack` 備份流程。

## 整理內容
- 36 個原 CSS 檔（包含 equipment-v83 舊基底）按原有載入順序整合至 `assets/css/app.css`，避免同一頁反覆載入歷年樣式檔。
- 將已隱藏但仍在 HTML 存在的「員工／管理者切換」按鈕與說明真正刪除；開啟後維持完整編輯模式。
- 去除設備主程式無用的身分按鈕監聽與切換畫面更新。保留 `setRole` 相容 API，避免舊模組呼叫時崩潰（仍不會切成員工模式）。
- 部署包移除 V11.12.0 舊檢查報告與已被 V10.5 替代的 V10.4 容量資料範本，現行 CAD 幾何、B 棟公豬欄配置與容量設定檔均保留。
- PWA 快取清單同步改為唯一樣式檔，快取名稱升級 V11.12.4，避免沿用舊版的快取。
- JavaScript 按功能模組保留獨立檔案，不合併成單一巨型程式，以免改變各模組的初始化順序與可獨立維護能力。

## 部署與資料注意
1. 本版是**網站程式**，不含裝置本機設備、管線、照片與 `.hwpack` 資料；不要將個人備份上傳公開 GitHub。
2. 更新前先保留目前裝置原有資料與已匯出的 `.hwpack`；沒有成功匯出時，不要清除瀏覽器、刪除 PWA 或覆蓋原裝置資料。
3. 將此 ZIP 解壓縮後的檔案（包含隱藏 `.nojekyll`）上傳到原 GitHub Pages 根目錄；**舊資產要從 GitHub 儲存庫刪除**，單純上傳新版不會自動刪掉遠端舊檔。
4. 舊加密 `.hwpack` 需用當時密碼；舊 `.hwb` 相容流程予以保留。
5. 若 Safari/iPad 已安裝 PWA，重新開啟並確認頁面顯示 V11.12.4；不要為更新畫面而直接清除站點資料。

## 清理範圍
本次清理的是「確定多餘的部署檔、樣式、舊身分選擇介面」，**沒有清除使用者裝置裡的設備記錄或照片**。不曾實際開啟你的真實 `.hwpack`，實體 Safari 資料移轉仍須在裝置上驗收。
