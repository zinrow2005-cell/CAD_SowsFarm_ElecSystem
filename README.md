## V11.12.19｜Apple 手機／平板 .hwpack 備份流程修正

- **iPad 匯出：**「儲存備份到指定資料夾」原本使用 Safari 不支援的 File System Access API，現在改成支援時優先開啟系統分享面板（可選「儲存到檔案」），否則直接啟動檔案下載；下方也永久保留「直接下載」備援入口。
- **iPhone 匯入：** Google Drive 的 iOS「檔案」雲端供應商資料夾可能回報「無法取得內容」。改為介面直接提示：先在 Google Drive App 將 `.hwpack` 複製／另存到「我的 iPhone／我的 iPad」或 iCloud Drive，再回本系統選擇本機檔案。網頁本身無法修復系統級檔案提供者故障。
- **結果回饋：** 儲存按鈕旁新增即時狀態；點擊後不再只有遠處文字提示。分享面板關閉或下載被觸發都不當作實際檔案儲存成功，仍需自行核對。
- **資料安全：** `.hwpack` 格式、CAD 與照片資料、儲存 API 均未變更；先留存原始備份，避免還原時整份覆蓋造成遺失。
- **相容性：** 舊 iPhone／iPad 若缺乏 Web Share 檔案支援，會改為下載；Safari 「檔案」App 可否成功存到 Google Drive 取決於裝置／雲端 App，請先在本機確認後再移動。
