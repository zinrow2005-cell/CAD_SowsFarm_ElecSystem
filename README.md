# 虎尾母豬場設備配置系統 V11.12.12 — 照片標記資訊卡＋端子追蹤整合版

## 本版功能（在 V11.12.11 上更新）

- 點照片標記，桌機在照片右邊立即顯示資訊卡；手機／平板在視窗底部顯示資訊卡，免向下捲動。
- 資訊卡內有「內容」「端子」「追蹤」三頁，包含名稱、用途、座標、鎖定狀態、端子及已建檔供電路徑。
- 端子頁直接選擇控制箱已建立的開關／端子，按「儲存連結」才寫入資料；也可跳到端子管理頁新增。
- 已連結時可定位到指定端子，並從該端子進入供電追蹤。
- 照片下方「標記清單」點選時不再把畫面強制捲動到表單。
- 原有單筆及整張照片的鎖定／解鎖、已鎖定保護、標記相對座標保持不變。

## GitHub 更新

1. 使用新版 ZIP 完整解壓並將內容部署到原本 GitHub Pages 來源目錄。
2. `release.json` 應顯示 `11.12.12` / `r4-photo-context-terminal-trace`。
3. PWA 更新或手機舊畫面未變時，可先關閉並重新開啟網頁；切勿直接清除網站資料，避免遺失本機尚未備份紀錄。

## 備份與安全

`.hwpack` 版本容器與 CAD 圖面格式均未更改。設備與照片資料可能只存放在目前裝置；每次更新前，請先產生完整私人備份並妥善保存。

**供電追蹤只顯示已建檔資料，不代表已實測確認。** 尚未建立端子或線路時，系統會顯示尚未建檔，不會推測接線。

詳見 `驗收紀錄_V11.12.12.md`。
