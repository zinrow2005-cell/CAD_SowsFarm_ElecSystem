# 虎尾母豬場設備配置系統 V11.12.24

GitHub Pages / PWA 完整部署包，修訂碼 `r16-cad-walkway-line-search-top`。

## 本版修正

- **刪除多餘斜線**：修正 `04_走道界線` 的 SVG 路徑。此前為了在 G-07 母豬通道保留開口，將上邊線拆成兩段，但仍留下 `Z` 封閉路徑，瀏覽器因此把 `M28.3750 47.0848` 與 `L0.8500 48.2348` 誤連為斜線。現改為明確的垂直左邊線，既有水平上／下邊線及 1.20 m 母豬通道缺口維持不變。
- **搜尋框靠頂部**：桌機上方中央搜尋框由 `top:68px` 改為 `top:9px`，寬、高、搜尋與定位功能不變；手機原有 `top:7px` 不變，並把原本會被搜尋框蓋住的快速圖層列往下排列。平板（761–1100px）也將左上快速圖層列移至搜尋框下方，避免撞在一起。
- **DXF**：原版 DXF 對應走道沒有該斜線；本版沿用相同正確 CAD 幾何，僅以 V11.12.24 檔名提供對應版本。其他線路、設備、G-07 通道及門位均未修改。
- `.hwpack` 格式不變；CAD 匯出中的 SVG/PNG/PDF 取自修正後的網頁 CAD 圖面。
