# 虎尾母豬場設備配置系統 V11.12.23

GitHub Pages / PWA 完整部署包。當前修訂：`r15-top-center-universal-search`。

## 本次變更：畫面上方中央全系統搜尋

- 在 CAD 介面上方中央顯示搜尋框，輸入即顯示匹配結果；手機以接近全寬方式顯示。
- 搜尋本機設備名稱、編號、類型、棟舍、規格、用途、備註、設備照片、照片標記、端子、維修／巡檢內容，亦可搜尋線路名稱及相關設備。
- 點擊搜尋結果直接定位 CAD；點「檔案」直接打開該設備的檔案。進階查詢延用現有完整搜尋與分類篩選。
- 鍵盤可按 `Ctrl+K` 或 `Cmd+K` 聚焦；Enter 選取結果，Esc 清除或關閉結果。
- 保留原有 CAD、照片標記與 A4 列印、水電管線、圖面 DXF/SVG/PNG/PDF 匯出，以及 `.hwpack` 備份還原。**未改動 CAD 幾何、現場資料結構或備份格式**。

## 沿用先前確認的設計

- 產房及新女豬育成區 G-07 旁專用母豬通道保留原配置；G-07 北門往產房方向外開，門洞／通道暫定 1.20 公尺。
- 設備檔案保留精簡介面，圖標外觀和實際位置預設收合；尺寸僅保留一套即時滑桿。

## 安裝／更新

1. 更新前，從目前系統匯出包含照片的完整 `.hwpack` 備份。
2. 解壓縮後，把 **所有檔案與資料夾**（包含 `assets/js/global-search-v111223.js`）上傳至 GitHub Pages 使用的目錄。
3. 等 GitHub Pages 部署成功後，開啟網站的 `release.json` 檢查 `version: 11.12.23`、`revision: r15-top-center-universal-search`。
4. 重新啟動網頁／PWA。**不要清除 Safari 網站資料**，以免抹除尚未備份的現場記錄。

## 驗收限制

本次測試包含 Chromium 模擬的桌機、平板、手機尺寸與隔離測試設備資料，詳見 `驗收紀錄_V11.12.23.md`。尚未用實體 iPhone/iPad Safari 與現場完整資料進行驗收。搜尋的是目前裝置已建檔的設備、管線與關聯資料，不包含其他獨立系統資料或所有未建立設備紀錄的底圖靜態文字。
