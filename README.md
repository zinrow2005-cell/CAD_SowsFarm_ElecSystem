# 虎尾母豬場設備配置系統 V11.12.13 — 全線路設備邊線自由吸附版

## 本版修正

- 電線、水管／給排水管、送料管、通風氣流示意線，都使用相同的設備外框吸附規則。
- 新畫線路時，點選設備外框任意位置，即記錄該處的連接錨點，不再強制連到設備中心。
- 完成線路後點選該路線：**黃色控制柄**代表已連結設備的節點，拖曳只能沿該設備外框移動；**青色控制柄**代表一般轉折點，可直接拖曳位置。
- 連結錨點使用 `point.edge.u`、`point.edge.v`（相對設備外框的局部座標），保留原始 `deviceId`、端子關聯及路線類別。設備旋轉、移動、調整外觀時，路線可跟隨設備幾何重新定位。
- 舊版僅有 `deviceId` 沒有 `edge` 的線路，會依相鄰線段呈現在設備邊線；修改過的連接點才會保存明確錨點，不會任意改寫舊紀錄。
- 每次調整連接點或轉折點，原路線的「已核對」狀態會清除；仍須到現場重新確認。
- 保留 V11.12.12 的照片標記資訊卡、照片標記位置鎖定、端子連結、供電追蹤與原 CAD 底圖。

## 操作方式

1. 在設備配置工具中選擇電線、水管、送料管或通風示意線，進入畫線狀態。
2. 先點設備想接出的邊線位置，再依路徑點選轉折或另一台設備，完成線路。
3. 已畫好的線路：在 CAD 圖上點選線路，再拖動黃色控制柄，沿設備輪廓找到想要的出入口位置；青色控制柄可移動一般轉折點。
4. 放開後會嘗試儲存並提示結果。位置變動後請重新核對實際管線。

## GitHub Pages 部署

1. **先在現有系統匯出完整私人 `.hwpack` 備份**，確認文件已存到指定資料夾。更新網站時不要清除站點資料。
2. 將此 ZIP 解壓後的檔案／資料夾上傳到 GitHub Pages 實際部署的來源目錄，整包覆蓋。不要直接把 ZIP 當網站上傳。
3. 用瀏覽器打開網站的 `release.json`，確認 `version` 是 `11.12.13`，`revision` 是 `r5-route-perimeter-anchors`。
4. 關閉舊 PWA 分頁後重新開啟；若仍顯示舊版，在不刪除本機設備資料的前提下重新整理靜態資源。

## 資料與驗收範圍

- 仍採既有 `.hwpack` 容器，不變更原始照片、現場設備與 CAD 幾何格式，只為已連結的路徑節點增加選用的 `edge` 欄位。
- 隔離測試涵蓋 4 類路線的建立與連接點拖曳、Node 幾何投影、JSON 資料正規化、設備幾何改變後的路線跟隨。
- 實機手機／iPad 觸控與 `.hwpack` 電腦、手機實際往返**尚未驗證**；尚不能代表真實設備連通或完成現場驗收。
