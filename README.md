# 虎尾母豬場設備配置系統 V11.12.15 — CAD 圖面匯出中心

## 新版功能

在「備份」工作區新增 **CAD 圖面匯出（DXF／SVG／PNG／PDF）** 入口，也可在原設備資料備份工具找到。這是**圖面交換功能**，不等同於包含照片與設備維修紀錄的 `.hwpack` 私人備份。

### 圖面範圍

- **完整配置圖（預設）**：從這台裝置目前已儲存的專案讀取 CAD 底圖＋**所有已建立**設備＋電線／水管／送料管／通風線，不因設備類別暫時隱藏而遺漏；底圖預設只含目前顯示的 CAD 基礎圖層。
- **僅 CAD 底圖**：不包含動態新增設備、線路。
- **只匯出目前開啟的圖層／設備類別**：底圖依目前顯示狀態、設備與線路依目前類別開關輸出。
- 可另勾選 **「另外包含隱藏的 CAD 底圖圖層」**；此選項會包含原本刻意隱藏的校核層或輔助圖層，請視用途啟用。
- 可選擇是否包含設備／線路名稱，以及深色或白底圖面。

### 四種輸出格式

| 格式 | 適用用途 | 技術註記 |
|---|---|---|
| DXF | AutoCAD／相容 CAD 系統編輯 | 實際生成 DXF R2007 (AC1021)，CAD 底圖和不同管線／設備按類別分層；使用 LWPOLYLINE、TEXT。原 SVG 曲線近似成分段向量線；設備標記簡化為可編輯向量示意外框＋文字，非原系統的全部特效符號。 |
| SVG | 網頁／向量圖／其他系統底圖 | 可縮放向量圖，包含當前 CAD 和動態設備／管線的座標及文字；不包含私人照片。 |
| PNG | 圖像檔／簡易貼圖 | 由 SVG 在本機產生；支援手機下載或分享。 |
| PDF | 列印／分享 | **直接下載單頁 A4 PDF**（含完整圖的點陣影像），依圖面比例自動選擇 A4 直式或橫式；不是可編輯 CAD 向量 PDF。 |

**座標與比例提醒：** CAD 座標使用現有 SVG 圖面的 CAD 數值；DXF 將 Y 軸改為標準笛卡兒朝上方向，並宣告公尺為單位。DXF 的線路端點會按照各設備的 `edge` 相對邊線錨點即時重新計算，設備旋轉或變更尺寸也可保留對應接點位置。若交給外部設計或施工廠商，仍應確認 DXF 縮放比例、座標軸與現場尺寸，不可直接當成正式施工測量依據。

## 操作方法

1. 在首頁開啟 **備份／完整備份與還原中心**，點 **「CAD 圖面匯出（DXF／SVG／PNG／PDF）」**。
2. 選擇 **圖面範圍**、**檔案格式**，依需要勾選名稱、隱藏的 CAD 圖層或白底。
3. 按 **預覽圖面**，確認 CAD 底圖、圖標與管線是否齊全。
4. 按 **下載匯出檔**，在瀏覽器／裝置的下載檔案區查看。建議先以 DXF／SVG 交換，PNG／PDF 適合閱讀與分享。

## 對資料與備份的影響

- 匯出讀取本機即時資料，不修改或刪除設備／照片／維修資料，不修改 CAD 圖面與圖層開關。
- **不修改 `.hwpack` 格式**，跨裝置移轉所有照片、維修資料仍請使用完整私人備份。
- GitHub Pages 更新程式不會自動同步本機資料。上傳新版 ZIP 前先在原裝置儲存 `.hwpack`，**不要**把含私人照片與資料的 `.hwpack` 放到公開 GitHub 儲存庫。
- 若瀏覽器阻止多次下載，請允許網站下載，或一次選擇一種格式。

## 已完成的驗收與限制

- 使用隔離 Chromium 在 **1360px 桌機** 及 **390px 手機** 模擬視窗，實際下載 DXF、SVG、PNG、PDF；四種均產生非空檔案。
- 使用 `ezdxf` 開啟 DXF 並確認底圖、設備和四類管線都有可解析實體；使用 `PyMuPDF` 確認 PDF 為 **單頁 A4**；PNG 確認圖面正常呈現。驗收結果見 `驗收紀錄_V11.12.15.md`。
- 尚未在使用者實際 iPhone／iPad、AutoCAD 或第三方管理系統裡驗證其接收端的特有相容性，也未對外部專案做任何修改。

部署完成後 `release.json` 應顯示 `version: 11.12.15`、`revision: r7-cad-exchange`；GitHub ZIP **先解壓縮**，再將內容全部覆蓋部署到 GitHub Pages 實際使用的專案目錄。
