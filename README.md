## GitHub Pages 正確更新與檢查
1. 先從運作中的舊版系統匯出完整 `.hwpack` 備份並確認有檔案。ZIP 是 **程式部署檔**，不是資料備份。
2. 解壓縮本 ZIP：將其中的 `index.html`、`sw.js`、`release.json`、`assets/`、`icons/`、`cad/` 等**內容**放到 GitHub Pages 網站根目錄，不要多包一層資料夾。
3. GitHub Actions/Pages 部署完成後，瀏覽 `/release.json` 應顯示版本 `11.12.8` 與 `r2-version-sync`。
4. 完全關閉已安裝的 APP，再開啟；首次使用網路連線開啟，重新整理一次。仍見 V11.12.7 時，先試瀏覽器強制重新整理（Windows Ctrl+Shift+R）或關閉重開 APP。**不要清除網站資料／IndexedDB / localStorage**，以免現場紀錄遺失。
5. 若 `/release.json` 仍是 404 或舊版，代表 GitHub Pages 尚未部署到此版本，檢查 Pages 設定的來源分支與目錄。

備註：靜態 PWA 更新需網路連線與頁面重新載入；不同裝置未重新開啟時可能短暫保留舊畫面。未經實體 iOS/Android 裝置測試，不保證所有特定裝置完全一致。
