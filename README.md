# V11.11.9｜完整備份無法匯出修正版

本次僅修正 `.hwpack` 完整加密備份的建立與下載，不改動 CAD 圖面、設備座標、照片、管線或本機資料結構。

- 備份流程清楚分兩步：① 建立並驗證加密備份；② 點擊「儲存備份到指定資料夾」或「直接下載 .hwpack（備援）」。**第一步完成不代表檔案已存到裝置**。
- 如果系統原本的檔案選擇器無法使用／被瀏覽器拒絕，備份仍保留在目前頁面，可直接點另一個下載連結，不會因選擇器失敗而清空。
- 照片縮圖遺失但原圖仍在時，臨時以原圖產生縮圖並封裝入 `.hwpack`，不變動原本 IndexedDB 照片資料。
- 照片原圖與縮圖都無法讀取時，列出有問題的照片 ID 並拒絕宣稱「完整備份」；不要清除原裝置資料。
- 額外的非必要健康檢查異常不再直接阻止已可核對照片的備份，但會顯示警告；備份加密、解密、SHA-256 核對仍須通過。
- 產生備份後可使用**真實使用者點擊**的下載連結觸發下載，避免非使用者手勢的瀏覽器自動下載限制。
- 沒有更動 `.hwpack` 格式（schema 2）與既有跨裝置還原流程，V11.11.8 資料維持相容。

## 最重要的操作提醒

1. 在原裝置切到管理者 → 完整專案備份 → 匯出完整專案。
2. 密碼至少 12 個字元，輸入兩次 → 點「① 建立並驗證加密備份」。
3. 等待驗證完成，**再點**「② 直接下載 .hwpack（備援）」或「儲存備份到指定資料夾」。
4. 打開下載資料夾／iPhone「檔案」App，確認確實有 `.hwpack`，且不是空檔。
5. 在另一裝置使用「檢查備份並預覽」核對密碼與照片，最後再考慮還原。

如果仍無法建立備份，請看視窗底部的「匯出未完成」錯誤訊息。不要為了排查而清除 Safari／Chrome 網站資料，也不要移除 PWA 或覆蓋原專案。

## 驗證範圍

- 以 Node.js WebCrypto 實際建立、加密、解密模擬照片備份；錯誤密碼與缺失照片保護均通過。
- 隔離 Chromium 390px UI 測試：點擊直接下載按鈕產生 `test_export.hwpack` 測試下載事件。
- 以上是測試資料，**沒有使用者真實的設備照片與裝置資料**；正式 GitHub Pages／Safari 安裝環境仍需部署後確認。

- 只讀取現有設備／線路與人工記錄的核對資料，不新增假連線、不修改原有 CAD 實體或設備座標。

- 圖面高亮為**目前記錄的關聯**，不表示當下帶電、有水、已送出飼料，也不能代替現場停電、驗電及安全檢查。
- 電力接線與管線若僅在 CAD 幾何上碰觸，但未建立設備端點，仍視為「未連接」。
- .hwpack 仍使用原有資料模型；此版不寫入新型資料欄位，因此無須轉檔。
- 更新前建議先從現有版本匯出完整 .hwpack，避免本機瀏覽器資料遺失。

- 勾選狀態、區域、共同規格或備註，先「預覽影響」確認確切設備與欄位，再按「確認套用」。
- 同組以 `arrayBatchId` 精確匹配，不會把名稱相似但不同組的設備改掉；同排已鎖定設備一律略過。
- 規格採用 `欄位名稱=內容` 每行一項，依名稱新增或更新，既有其他規格保留；最多 12 項且不得超過單台 30 項上限。
- 絕不批次變動設備 ID、名稱、CAD／圖示位置、照片、端子、電力／水路／飼料管線、維修紀錄。
- 整批一次存檔與復原／重做；若本機儲存失敗，系統會顯示原有的警告，應立即匯出緊急備份。
- 為避免誤分組，從已拆分的設備執行「複製」或「連續複製」，複製品不再繼承原 `arrayBatchId`。
- 沒有修改 `.hwpack` 備份格式。更新前請匯出完整備份。

## V11.10.8 巡檢維修管理
管理者可從設備工具開啟「巡檢與維修」，可單台或同一拆分群組批次巡檢、設定正常／異常／停用／維修中、連結既有照片，並自動建立工作單。可查看待修工作單並人工結案。狀態是手動巡檢記錄，並非即時感測。

## V11.10.9｜CAD 全場巡檢狀態視覺化
- 新增 CAD 右側可收合「設備狀態」入口：顯示異常／維修中數量、全部／正常／異常／停用／維修中／未巡檢篩選與設備清單。
- 點「定位」自動移到該設備 CAD 圖示位置；點「紀錄」進入現有巡檢／維修中心。不會建立額外資料庫。
- 異常、維修中及停用設備以額外色框提示；設備是否已安裝的原有指示點保留。
- 狀態篩選只淡化不符合者，**不會刪除、隱藏設備或改變圖面／管線與照片**。
- 首頁與專屬工作區不出現 CAD 狀態浮窗；狀態資料來自人工巡檢，非即時監測。
- 切換手機／平板的控制列保持原有方式，瀏覽器測試非真實 Safari 實機驗收。


## V11.11.8 大型風扇等距陣列拉長
- 管理者選取未鎖定的風扇陣列，拖曳任一端白綠色圓點調整整排長度，另一端固定。每個風扇圖示維持原尺寸，僅變更中心間距。
- 編輯視窗可直接輸入「整排總長度」或「中心間距」，兩者自動換算；2～20 台共用。
- 會同步更新旋轉外框與 CAD 吸附判斷；不會修改個別真實接線與設備實際位置。原有 `.hwpack` 仍相容。
- 更新前請備份現有資料，現場仍需核對牆間實際淨距。


## V11.11.8｜自由角度、工具圖示 75%、尺寸即時預覽

- 水簾等區段設備、排風扇等陣列設備的**上下端點可自由旋轉**。選取設備後拉兩端圓點，另一端固定；沿牆吸附需主動勾選，端點調整不受自動牆線或其他圖示磁吸限制。
- 兩點建立的設備使用使用者指定的起終點角度，建立時不再套用通用格點對中心位置的吸附。
- 設備圖庫、編輯工具及各主要工具列的**圖示視覺尺寸**改為舊版的 75%；按鈕的可點擊範圍盡量維持不變。CAD 上已擺放設備的尺寸不會因此自動縮小。
- 管理者開啟設備編輯後，調整「整體大小、左右寬度、上下高度、角度及長條設定」會立即重畫 CAD **預覽**。只在按下儲存後更新設備資料；關閉編輯會捨棄尚未儲存的預覽。
- 實驗性隔離 Chromium 測試通過 1440、768、390、320px 尺寸即時預覽；自由角度端點在 1440 與 390px 測得 33°、41° 等非水平垂直方向。水簾端點另測得 336.56°，儲存長度／厚度生效。**未在實體 Safari 或已部署網站驗證。**
