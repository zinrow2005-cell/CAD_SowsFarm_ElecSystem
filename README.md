# 虎尾母豬場設備配置系統 V11.10.3 — GitHub Pages 上傳精簡版

本 ZIP 內容共 **88 個檔案**，已去除網站運行不需要的歷史測試報告、版本文件、舊 CAD 底圖與範例設定。
**正式系統功能程式、現在使用的 CAD DXF、配置 JSON、PWA 安裝圖示與離線資源皆保持原樣。**

## 如何更新 GitHub

1. 在自己的電腦將本 ZIP **解壓縮**。
2. 登入你的 GitHub 儲存庫，確認 GitHub Pages 使用的分支及資料夾（通常是 `main` 的根目錄）。
3. 點選 **Add file → Upload files**。
4. 進入解壓縮的資料夾，將**裡面的所有檔案與資料夾**一起拖入上傳區，不要直接上傳 ZIP 檔，也不要再拖入完整版的 `docs/` 或 `tests/`。
5. 確認 `index.html` 位於儲存庫網站根目錄，並且 `assets/`、`icons/`、`cad/` 目錄結構完整，再按 **Commit changes**。
6. 等待 GitHub Pages 發佈，重新開啟網站及 PWA。

### 重要提醒
- 這是 **公開網站程式部署包**，不包含、也不應上傳任何私人設備照片、私人 `.hwpack` 備份或密碼。
- 原有設備資料儲存在個別裝置的本機儲存區，版本部署不等於備份或跨裝置同步。升級前請先自行匯出 `.hwpack`。
- 因檔案少於 100 個，可在 GitHub 網頁上一次上傳；如果你的儲存庫同時有其他新增檔案，請只選取此資料夾內的 88 個檔案。
- 不要刪除目前 GitHub 內的其他專案檔案；這份只負責更新執行所需的檔案。
- 完整版的歷史 CAD、文件與測試紀錄請留在電腦作為參考，不必上傳 GitHub Pages。

## V11.10.3｜設備圖示左右寬度／上下高度獨立調整
- 管理者選取未鎖定設備 → 編輯內容 → 圖標外觀。
- 大小 50–300%，寬度 30–300%，高度 30–300%；未設定的舊資料寬高均為 100%。
- 兩軸倍率儲存在設備與模板資料中，支援本機儲存、備份匯出、復原／重做。
- 360° 旋轉、全邊框吸附使用相同寬高變形後的幾何；原始 CAD 設備座標及管線端點不變。
